## 🚀 En qué estoy trabajando

### 🤖 Asistente de WhatsApp con IA para centros de estética

Responde consultas de clientes, informa servicios y precios reales y ayuda con los turnos, sin inventar información. Incluye evaluaciones automáticas para medir la calidad de las respuestas del agente.

`TypeScript` `Node.js` `Fastify` `PostgreSQL` `Drizzle` `Claude API` `Vitest`

### 🏪 Sistema de ventas, stock y caja para kioscos y almacenes

App web multi-negocio (PWA) que funciona en celular y PC: ventas, control de stock, caja y estadísticas. Con aislamiento de datos por negocio, CI y tests de punta a punta.

`Next.js` `React` `TypeScript` `Supabase` `PostgreSQL` `Tailwind` `Playwright`
